# TurboSMS для EspoCRM

Розширення додає до EspoCRM інтеграцію з сервісом [TurboSMS](https://turbosms.ua/).
Воно дає змогу надсилати SMS, Viber та гібридні повідомлення безпосередньо з CRM
через стандартний механізм SMS-провайдерів EspoCRM.

## Можливості

- надсилання SMS, Viber і гібридних повідомлень;
- окремі імена відправника для SMS та Viber;
- налаштування тайм-ауту й журналювання запитів;
- безпечне зберігання API-токена в секретах застосунку EspoCRM;
- перенесення токена зі старого формату під час перебудови системи.

## Встановлення

1. Створіть ZIP-архів вмісту цього репозиторію.
2. У EspoCRM відкрийте **Адміністрування → Розширення** і завантажте архів.
3. Перейдіть до **Адміністрування → Інтеграції → TurboSMS**, вкажіть API-токен та
   параметри відправлення.

Після встановлення виберіть `TurboSms` як SMS-провайдера у налаштуваннях EspoCRM.

## Вимоги

- EspoCRM 10.0 або новішої версії;
- PHP 8.3 або новішої версії;
- обліковий запис і API-токен TurboSMS.
